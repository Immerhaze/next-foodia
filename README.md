🇪🇸 Español
Generador de recetas con IA que crea planes de alimentación personalizados según tu perfil de salud, preferencias dietéticas, alergias y presupuesto semanal.
🔗 Ver Demo
¿Qué hace?
Completa un formulario con tus datos físicos (peso, talla, edad, nivel de actividad), tipo de dieta (vegana, omnívora, pescetariana, etc.), alergias o intolerancias, condiciones médicas y presupuesto semanal en CLP — y la app genera un plan de recetas completamente personalizado.
Los resultados se pueden descargar en PDF o enviar directamente a tu correo.
Stack

Next.js — App Router
Vercel AI SDK — generación de recetas con IA
TypeScript
Tailwind CSS

Funcionalidades

🧬 Personalizado por tipo de cuerpo, objetivo (subir/bajar peso) y dieta
🚫 Filtrado por alergias e intolerancias (frutos secos, gluten, lactosa, etc.)
🏥 Consideración de condiciones médicas (diabetes, hipertensión, intestino irritable, etc.)
💰 Plan ajustado al presupuesto semanal en CLP
📄 Exportación a PDF y envío por correo

Correr localmente
bashgit clone https://github.com/Immerhaze/next-foodia
cd next-foodia
npm install
npm run dev

Requiere una API key de Vercel AI SDK en .env.local


🇺🇸 English <a name="english"></a>
AI-powered recipe generator that creates personalized meal plans based on your health profile, dietary preferences, allergies and weekly budget.
What it does
Fill out a form with your physical data (weight, height, age, activity level), dietary type (vegan, omnivore, pescatarian, etc.), any allergies or intolerances, medical conditions and weekly budget in CLP — and the app generates a fully personalized recipe plan.
Results can be downloaded as PDF or sent directly to your email.
Tech Stack

Next.js — App Router
Vercel AI SDK — AI-powered recipe generation
TypeScript
Tailwind CSS

Features

🧬 Personalized by body type, goal (gain/lose weight) and diet
🚫 Allergy & intolerance filtering (nuts, gluten, lactose, etc.)
🏥 Medical condition awareness (diabetes, hypertension, IBS, etc.)
💰 Budget-aware meal planning (CLP)
📄 PDF export & email delivery

Run locally
bashgit clone https://github.com/Immerhaze/next-foodia
cd next-foodia
npm install
npm run dev

Requires a Vercel AI SDK API key in .env.local
